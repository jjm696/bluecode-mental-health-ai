# 面试三分钟介绍稿

## 版本一

这个项目叫“AI 心理健康助手”，我把它做成了前后台双端结构。用户端主要负责 AI 咨询、情绪日记记录和心理知识库浏览，后台端负责知识文章管理、咨询记录查看、情绪日志复核和数据分析。项目的核心不是单纯做一个聊天页面，而是希望形成“用户输入内容、AI 生成建议、后台沉淀数据并做风险复核”的业务闭环。

技术上，前端我使用了 Vue3、Vite、Vue Router、Pinia 和 Element Plus，后端用 Express，数据库用 MySQL。数据库层我重点做了表结构拆分，比如把咨询会话和消息拆表、情绪日志和 AI 分析结果拆表、文章和标签关系拆表，这样后续做统计分析和扩展都更清晰。

在功能实现上，我完成了管理员登录鉴权、文章的新增编辑删除、文章详情、后台多业务分页查询，以及用户端首页、知识库、文章详情、AI 咨询演示页和情绪日记页。这个项目比较适合写在简历里，是因为它同时能体现前端页面组织、后端接口分层、数据库建模和前后端联调，而不是只有单一页面展示。

## 版本二

我做的是一个 AI 心理健康辅助系统，包含用户端和后台管理端。用户端提供 AI 咨询、情绪日记和知识库阅读，后台管理端提供文章管理、咨询记录查看、情绪日志风险复核和数据分析。后端用 Express + MySQL 做数据支撑，前端用 Vue3 + Element Plus 实现页面和交互。

这个项目的重点在于业务抽象。我没有把它做成一个简单的聊天 Demo，而是先设计了用户、文章、咨询会话、咨询消息、情绪日志、AI 分析结果这些核心数据实体，再按这些实体去做前后台页面和接口，这样结构更稳定，也更容易在面试里讲清楚设计思路。

如果面试官继续追问，我一般会重点讲三个点：第一是为什么这样拆表；第二是后台分页查询和文章增删改查怎么设计；第三是为什么这个项目具备真实业务闭环，而不是静态页面拼接。
