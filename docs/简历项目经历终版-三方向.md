# 简历项目经历终版（三方向）

## 1. Java后端方向

### 项目名称

AI 心理健康助手

### 项目描述

独立完成 AI 心理健康助手前后台双端项目开发，后端基于 Spring Boot + MyBatis + MySQL 完成用户、知识文章、咨询会话、咨询消息、情绪日志及 AI 分析结果等核心数据建模，设计并实现管理员登录鉴权、用户注册登录、文章增删改查、咨询会话落库、情绪日记落库和多业务分页查询；同时接入 DeepSeek 兼容接口实现 AI 对话能力，并根据用户输入做情绪场景识别与风险分级，支撑后台咨询记录与情绪日志复核。

### 可拆成简历要点

- 基于 Spring Boot + MyBatis + MySQL 设计并实现 AI 心理健康助手后端，完成用户、文章、会话、消息、情绪日志等核心表结构建模
- 实现管理员登录鉴权、用户注册登录、文章增删改查、多业务分页查询等后台核心接口
- 实现用户咨询消息与 AI 回复双向落库，构建咨询会话与消息历史管理能力
- 接入 DeepSeek 兼容 API，实现心理陪伴式对话回复，并加入情绪场景识别与风险等级判断逻辑
- 支持后台对咨询记录和情绪日志进行结构化查看，为后续风险复核与统计分析提供数据基础

## 2. Java全栈方向

### 项目描述

独立开发 AI 心理健康助手前后台双端系统，前端采用 Vue3 + Vite + Element Plus 构建用户端与后台管理端，后端采用 Spring Boot + MyBatis + MySQL 实现业务接口与数据持久化。项目覆盖用户注册登录、首页引导、知识库浏览、文章详情、情绪日记、AI 咨询、个人记录，以及后台文章管理、咨询记录管理、情绪日志管理和数据分析等模块；同时实现 DeepSeek 对话接入、会话消息落库、近实时轮询同步和登录态隔离。

### 可拆成简历要点

- 独立完成 Vue3 前后台双端页面开发与 Spring Boot 后端接口设计，实现完整业务闭环
- 搭建用户端首页、知识库、情绪日记、AI 咨询、我的记录等模块，并实现后台管理系统
- 设计并实现 Spring Boot + MyBatis + MySQL 数据层，完成登录鉴权、文章管理、会话管理和情绪记录接口
- 接入 DeepSeek 兼容 API，支持真实 AI 对话、消息落库和咨询历史管理
- 使用轮询机制实现用户端与后台端近实时数据同步，提升系统演示与使用体验

## 3. 前端方向

### 项目描述

负责 AI 心理健康助手项目的前端整体设计与实现，基于 Vue3 + Vite + Element Plus 构建用户端和后台管理端双端界面，完成首页、登录注册、知识库、文章详情、情绪日记、AI 咨询、个人记录，以及后台数据分析、文章管理、咨询记录、情绪日志等核心页面；封装通用布局、筛选表单、状态管理和接口请求层，并结合 Spring Boot + MySQL 后端实现真实联调。

### 可拆成简历要点

- 使用 Vue3 + Vite + Element Plus 实现 AI 心理健康助手前后台双端页面
- 搭建登录注册、知识库、情绪日记、AI 咨询、我的记录等用户端模块及后台管理模块
- 封装通用布局、导航、筛选组件、接口请求层与 Pinia 状态管理，提升页面复用性
- 完成用户端与后台端登录态隔离、分页查询、详情弹窗、近实时轮询刷新等交互逻辑
- 对接 Spring Boot + MySQL 后端与 DeepSeek 兼容接口，实现真实数据联调和 AI 咨询体验
