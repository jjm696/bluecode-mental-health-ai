# AI 心理健康助手 最终测试清单

## 一、启动检查

### 1. 启动 Spring Boot 后端

```powershell
cd "D:\实战项目\心理健康助手\code\ai-vue\springboot-backend"
mvn spring-boot:run
```

检查：

- 访问 `http://127.0.0.1:8080/health`
- 返回 `code=0`

### 2. 启动前端

```powershell
cd "D:\实战项目\心理健康助手\code\ai-vue"
npm run dev
```

检查：

- 打开 Vite 本地地址
- 首页正常显示

## 二、用户端测试

### 1. 首页

访问 `/`

检查：

- 导航栏正常
- “登录 / 注册 / 管理端”入口正常
- 首页主视觉、按钮、功能卡片正常显示

### 2. 用户注册

访问 `/register`

检查：

- 输入用户名、昵称、手机号、密码、确认密码
- 注册成功后自动登录
- 右上角显示用户昵称而不是“登录/注册”
- 数据库 `users` 表新增用户

### 3. 用户登录

访问 `/login`

检查：

- 使用刚注册的用户登录成功
- 刷新页面后仍保持登录状态
- 点击“退出”后登录状态清除

### 4. 知识库

访问 `/knowledge`

检查：

- 推荐阅读正常
- 文章列表正常
- 点击任意文章进入详情页

### 5. 文章详情

访问 `/knowledge/:id`

检查：

- 页面正常显示文章标题、摘要、正文、标签
- 点击“返回知识库”可回到列表页
- 阅读量进入一次后应增加
- 数据库 `knowledge_articles.read_count` 变化

### 6. 情绪日记

访问 `/emotion-diary`

检查：

- 未登录时保存会提示先登录
- 登录后填写情绪、内容、睡眠评分、压力评分
- 点击保存后提示成功
- 数据库新增：
  - `emotion_logs`
  - `emotion_ai_analyses`

### 7. AI 咨询

访问 `/consultation`

检查：

- 未登录时进入会提示先登录
- 登录后可以发送消息
- 发送时显示“AI 正在思考中”
- 返回消息正常显示
- 左侧会话历史自动更新
- 可新建会话
- 可删除会话
- 数据库新增：
  - `consultation_sessions`
  - `consultation_messages`

### 8. 我的记录

访问 `/my-records`

检查：

- 可以看到自己的情绪日记记录
- 可以看到自己的咨询历史
- 未登录时会跳转登录
